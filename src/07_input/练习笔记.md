1、signal函数说明：

```c
#include <signal.h>

typedef void (*sighandler_t)(int);
sighandler_t signal(int signum, sighandler_t handler);
```

> DESCRIPTION
The behavior of signal() varies across UNIX versions, and has also varied historically across different versions of Linux.   Avoid  its  use: use sigaction(2) instead.  See Portability below.
signal() sets the disposition of the signal signum to handler, which is either SIG_IGN, SIG_DFL, or the address of a  programmer-defined  function (a "signal handler").

struct input_event各个字段的含义：

```
struct input_event {
	...
	__u16 type;
	__u16 code;
	__s32 value;
};
```
其中type表示上报的event 类型，可能的取值：
```
#define EV_SYN			0x00
#define EV_KEY			0x01
#define EV_REL			0x02
#define EV_ABS			0x03
#define EV_MSC			0x04
#define EV_SW			0x05
#define EV_LED			0x11
#define EV_SND			0x12
#define EV_REP			0x14
#define EV_FF			0x15
#define EV_PWR			0x16
#define EV_FF_STATUS		0x17
#define EV_MAX			0x1f
```
code表示上报的是哪一个，比如电容屏把屏幕分为了多个区域，code对应的区域，或者表示哪个按键，比如KEY_A

value表示上报的数值是多少，比如相对位移/绝对位移的位移值
