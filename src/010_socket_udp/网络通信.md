# 网络通信

## 一、网络通信概述

网络通信实质上也是数据的传输；

数据传输的三要素：

- 源
- 目的
- 长度

网络传输使用CS架构：

- 服务器：
  - 被动地响应请求；

- 客户端：
  - 主动地发起请求
- 传输方式：
  - UDP：不可靠的，不关心目的的数据接受，负责大量数据的批量传输，速度最快；视频数据等信息量较大的数据，就需要通过UDP方式来传输；
  - TCP：可靠的，具备重传机制；通过三次握手和四次挥手来确保数据传输的完整性；适用于精准数据传输的场景，比如控制信号，文件数据等；



## 二、IP和端口

上述提到了数据传输的三要素：源、目的、长度

对于网络传输的源、目的等位置信息的传输，单纯使用IP无法完整的表述一个准确的位置，必须要加上端口的区分；例如浏览器场景，可能会有多个同名IP对服务器进行访问，而返回时，服务器必须根据端口的区别，将数据传回；

假如电脑上有两个软件：ssh client和浏览器访问同一个网站，ssh想使用ssh服务，浏览器想使用http服务，这两个软件访问的服务器是同一个，IP相同，那他们怎么声明自己想要什么服务，通过目的端口来区分，一般来说，80端口是http服务，22端口是ssh服务；

**综上在网络传输中，需要使用IP和端口来表示源或者目的**





## 三、TCP传输

### 调用方法

#### 服务器

- 打开套接字

  ```c
  #include <sys/types.h>
  #include <sys/socket.h>
  
  int socket(int domain, int type, int protocol);
  // AF_INET为IPV4协议，AF_INET6为IPV6协议；
  ```

- 绑定

  ```c
  int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
  ```

  绑定指定的IP地址和端口，用来选择监听什么端口的数据；
  const struct sockaddr *addr该参数通常转化成struct sockaddr_in进行设置，例如：

  ```c
  struct sockaddr_in svr_addr;
  memset(&svr_addr, 0, sizeof(struct sockaddr_in));
  svr_addr.sin_family = AF_INET;
  svr_addr.sin_port  = htons(SOCKET_SERVER_PORT);
  svr_addr.sin_addr.s_addr   = INADDR_ANY;
  ```

  其中，端口号需要经过转化才能够赋值给sin_port：

  ```c
  #include <arpa/inet.h>
  uint16_t htons(uint16_t hostshort);
  //The htons() function converts the unsigned short integer hostshort from host byte order to network byte order.
  ```

  将host字节序转化成网络字节序；

- 监听

  ```c
  int listen(int sockfd, int backlog);
  ```

  监听端口的链接请求，第二个参数backlog设置最大的同时连接数：The backlog argument defines the maximum length to which the queue of pending connections for sockfd may grow.

- 接收请求，获取到客户fd，建立服务器与客户端的连接（**TCP是可靠的，有连接的传输**）；
  
```c
  int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
```

- 对数据进行接受和处理，根据请求准备需要返回的数据
  
```c
  ssize_t recv(int sockfd, void *buf, size_t len, int flags);
```

  // 从sockfd所指的套接字获取数据；flag通常设置为0，随协议的配置而变化，在为0的情况下与read无差别；

- 发送数据返回给客户端fd；
  
  ```
  ssize_t send(int sockfd, const void *buf, size_t len, int flags);
  ```
  
  发送数据给套接字sockfd，flag设置于recv一致；



#### 客户端

- 打开客户端套接字
  
  ```c
  #include <sys/types.h>
  #include <sys/socket.h>
  
  int socket(int domain, int type, int protocol);
  // AF_INET为IPV4协议，AF_INET6为IPV6协议；
  ```
  
  创建套接字的方式与客户端一致，使用同一协议类型，protocol依旧设置为0；
  
- 连接服务器
  
  ```c
  int connect(int sockfd, const struct sockaddr *addr,
                     socklen_t addrlen);
  ```
  
  在这里需要指定目标服务器的位置，即IP和端口，这等于设置了目的是哪里，**牢记数据传输三要素**；设置方式和服务端类似：
  
  ```c
  struct sockaddr_in svr_addr;
  memset(&svr_addr, 0, sizeof(struct sockaddr_in));
  svr_addr.sin_family = AF_INET;
  svr_addr.sin_port   = htons(SOCKET_SERVER_PORT);
  if (inet_pton(AF_INET, SOCKET_SERVER_IP, &svr_addr.sin_addr) <= 0) {
      LOG_DEBUG("inet_pton IP address failed!");
      return -1;
  }
  // connect
  if (connect(g_cln_sock, (struct sockaddr*)&svr_addr, sizeof(struct sockaddr_in)) != 0) {
      LOG_DEBUG("Bind socket failed: %s", strerror(errno));
      return -1;
  }
  ```
  
  设置Ip的时候，需要把字符串转化成网络字节序：
  
  ```c
  int inet_pton(int af, const char *src, void *dst);
  //This  function converts the character string src into a network address structure in the af address family, then copies the network address structure to dst.  The af argument must be either AF_INET or AF_INET6.  dst is written in network byte order.
  ```



知识点：

1. 客户端和服务端连接建立的标志：

- TCP
  服务端通过accept获取到了客户端的套接字fd，客户端调用connect 返回了0，表示连接成功；
- UDP
  该方式无连接，数据发送的条件是：- 服务端bind成功； - 客户端调用**`sendto()` 或 `recvfrom()` 无错误**：

2. struct sockaddr_in结构体中的元素sin_port、sin_addr都是网络字节序，转化成常用的形式需要调用接口：

   | 端口号整数 | ->   | htons                 | sockaddr_in.sin_port |
   | ---------- | ---- | --------------------- | -------------------- |
   | 端口号整数 | <-   | ntohs                 | sockaddr_in.sin_port |
   | IP字符串   | ->   | inet_pton / inet_aton | sockaddr_in.sin_addr |
   | IP字符串   | <-   | inet_ntop / inet_ntoa | sockaddr_in.sin_addr |



#### 知识点：

子进程退出之后，并不会真正的销毁，而是会留下一个僵死进程<defunct>, 此时需要父进程调用exit去销毁子进程的资源，如果父进程对子进程的资源不感兴趣，可以调用signal(SIGCHLD, SIG_IGN);这里表示忽视SIGCHLD这个信号，从而可以在子进程自己退出时自动销毁僵尸进程；



## 四、UDP传输

### 调用方法

#### 服务器

- 打开套接字：

  ```c
  #include <sys/types.h>
  #include <sys/socket.h>
  
  int socket(int domain, int type, int protocol);
  // AF_INET为IPV4协议，AF_INET6为IPV6协议；
  // UDP时，type为SOCK_DGRAM，tcp时为SOCK_STREAM，此处存在差异
  ```

- 绑定IP和端口，同TCP

- 无需listen和accept

- 接受数据：
  使用recv函数：

  ```c
  int recv_cnt = recv(cln_sock, recv_buf, MAX_SOCKET_MSG_LEN, 0);
  if (recv_cnt <= 0 && accept_retry > 0) {
  LOG_DEBUG("recv  msg from client socket failed: %s", strerror(errno));
  goto re_accpet;
  }
  ```

  或者使用recvfrom函数，需要指明来源：

  ```c
  char recv_buf[MAX_SOCKET_MSG_LEN] = {0};
  struct sockaddr_in cln_addr;
  socklen_t len = (socklen_t)sizeof(struct sockaddr_in);
  // recvfrom
  int recv_cnt = recvfrom(g_srv_sock, recv_buf, MAX_SOCKET_MSG_LEN, 0, (const struct sockaddr*)&cln_addr, &len);
  if (recv_cnt <= 0) {
      LOG_DEBUG("recv msg from client socket failed: %s", strerror(errno));
  ```

- 发送数据：
  使用send函数

  ```c
  int send_cnt = send(cln_sock, SOCKET_SERVER_RESPONSE_KEY, strlen(SOCKET_SERVER_RESPONSE_KEY), 0);
  if (send_cnt < strlen(SOCKET_SERVER_RESPONSE_KEY) && accept_retry > 0) {
  LOG_DEBUG("send  msg from client socket failed: %s", strerror(errno));
  goto re_accpet;
  }
  ```

  或使用sendto函数，需要指明目的：

  ```C
  // sendto
  int send_cnt = sendto(g_srv_sock, SOCKET_SERVER_RESPONSE_KEY, strlen(SOCKET_SERVER_RESPONSE_KEY), 0,
  (const struct sockaddr*)&cln_addr, len);
  if (send_cnt <= 0) {
  LOG_DEBUG("send msg to client socket failed: %s", strerror(errno));
  continue;
  }
  ```

#### 客户端

- 与TCP完全一致，仅需要在创建套接字时**修改type为SOCK_DGRAM**；

- connect函数可选择不使用，两种通信方式：

  不用connect + sendto/recvfrom接口
  使用connect + send/recv接口
