# 汇编语言常用命令

### **ARM汇编常用指令表**

| **指令类别**  | **指令**      | **语法示例**            | **作用**                                            | **备注**                           |
| :------------ | :------------ | :---------------------- | :-------------------------------------------------- | :--------------------------------- |
| **数据传输**  | `MOV`         | `MOV Rd, Operand2`      | 将数据（立即数或寄存器）移动到目标寄存器。          | 如 `MOV R0, #10`                   |
|               | `LDR`         | `LDR Rd, [Rn, #offset]` | 从内存加载数据到寄存器（支持偏移寻址）。            | 如 `LDR R0, [R1, #4]`              |
|               | `STR`         | `STR Rd, [Rn, #offset]` | 将寄存器数据存储到内存（支持偏移寻址）。            | 如 `STR R0, [R1, #8]`              |
| **算术运算**  | `ADD`         | `ADD Rd, Rn, Operand2`  | 加法运算（支持立即数或寄存器）。                    | 如 `ADD R0, R1, R2`                |
|               | `SUB`         | `SUB Rd, Rn, Operand2`  | 减法运算。                                          | 如 `SUB R0, R1, #5`                |
|               | `MUL`         | `MUL Rd, Rn, Rm`        | 乘法运算（结果32位）。                              | 如 `MUL R0, R1, R2`                |
| **逻辑运算**  | `AND`         | `AND Rd, Rn, Operand2`  | 按位与。                                            | 如 `AND R0, R1, #0xFF`             |
|               | `ORR`         | `ORR Rd, Rn, Operand2`  | 按位或。                                            | 如 `ORR R0, R1, R2`                |
|               | `EOR`         | `EOR Rd, Rn, Operand2`  | 按位异或。                                          | 如 `EOR R0, R1, R2`                |
| **移位操作**  | `LSL`         | `LSL Rd, Rn, #imm`      | 逻辑左移。                                          | 如 `LSL R0, R1, #2`                |
|               | `LSR`         | `LSR Rd, Rn, #imm`      | 逻辑右移。                                          | 如 `LSR R0, R1, #3`                |
| **比较/条件** | `CMP`         | `CMP Rn, Operand2`      | 比较两个操作数并更新标志位（不保存结果）。          | 如 `CMP R0, #10`                   |
|               | `B` / `BX`    | `B label` 或 `BX Rm`    | 无条件跳转（`B`）或跳转到寄存器指定的地址（`BX`）。 | 如 `B loop` 或 `BX LR`（函数返回） |
|               | `BEQ` / `BNE` | `BEQ label`             | 条件跳转（`BEQ`为相等时跳转，`BNE`为不等时跳转）。  | 需配合 `CMP` 使用                  |
| **栈操作**    | `PUSH`        | `PUSH {reg1, reg2}`     | 将寄存器压栈（栈指针递减）。                        | 如 `PUSH {R0, R1, LR}`             |
|               | `POP`         | `POP {reg1, reg2}`      | 从栈弹出数据到寄存器（栈指针递增）。                | 如 `POP {R0, R1, PC}`（函数返回）  |
| **分支/调用** | `BL`          | `BL function_name`      | 跳转到子函数并保存返回地址到 `LR`（`R14`）。        | 如 `BL printf`                     |
| **其他**      | `NOP`         | `NOP`                   | 空操作（用于延时或对齐）。                          |                                    |
|               | `SWI` / `SVC` | `SWI #0`                | 软中断（ARMv7之前用`SWI`，之后用`SVC`）。           | 如 `SVC 0`（触发系统调用）         |

------

### **关键说明**

1. **操作数格式**

   - `Operand2` 可以是：
     - 立即数（如 `#10`）
     - 寄存器（如 `R1`）
     - 带移位的寄存器（如 `R2, LSL #2`）。

2. **条件执行**
   ARM指令可附加条件码（如 `ADDEQ R0, R1, R2`），仅当条件满足时执行。
   **常见条件码**：

   - `EQ`（相等）、`NE`（不等）
   - `GT`（大于）、`LT`（小于）
   - `CS`（进位置位）、`CC`（进位清除）

3. **内存访问**

   - `LDR/STR` 支持多种寻址模式：

     asm

     

     复制

     

     下载

     ```
     LDR R0, [R1]          ; 从R1指向的地址加载
     LDR R0, [R1, #4]!     ; 加载后R1 += 4（前变址）
     LDR R0, [R1], #4      ; 加载后R1 += 4（后变址）
     ```

4. **Thumb模式**
   在Thumb指令集（16位编码）中，部分指令功能受限（如 `MOV` 不能使用大立即数）。
