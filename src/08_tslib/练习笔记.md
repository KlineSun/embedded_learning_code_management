### calloc和malloc的差异：

函数原型：

void* malloc(size_t size);

void* calloc(size_t num, size_t size);

- calloc需要传入申请的元素个数，以及单个元素的大小
- calloc会将申请的内存清零，而malloc不会，需要自行清零；
- calloc运行稍慢，因为需要清零内存；



### 知识点：

- hexdmup命令常用于查看文件或16进制文件的指令，语法如下：
  hexdump [选项] 文件名

  常用选项：

  ### **常用选项**

  | 选项        | 说明                                    |
  | :---------- | :-------------------------------------- |
  | `-C`        | 经典十六进制 + ASCII 双栏显示（最常用） |
  | `-n <长度>` | 仅显示前 `<长度>` 字节                  |
  | `-s <偏移>` | 从指定偏移量开始显示                    |
  | `-v`        | 显示所有数据（默认会省略重复行）        |
  | `-e <格式>` | 自定义输出格式（高级用法）              |
